# Maths 2 Command Center — IITM BSMA1003

Static Vercel-ready web app for Mathematics for Data Science II.

## Files
- `index.html` — app shell
- `styles.css` — responsive UI
- `data.js` — syllabus, teacher lessons, drills, PYQ index metadata, resources
- `app.js` — interactions, progress, practice, error bank, mocks, scorebook

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy on Vercel
Import this folder/repository into Vercel. No build command and no environment variables are required.

## Notes
- The public IITM BSMA1003 degree course page lists 11 coursework weeks. This app uses Week 12 as an explicit revision/integration layer because the requested plan is 12 weeks.
- Dates in the dashboard: Quiz 1 15 Nov 2026, Quiz 2 5 Dec 2026, End Term 10 Jan 2027.
- PYQ paper PDFs are not redistributed inside the package. The PYQ Vault links to the public paper index and current learning resources.
